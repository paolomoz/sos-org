Προετοιμασία για τον Διαλογισμό SOS:

O Διαλογισμός SOS δεν απαιτεί καμία ειδική θέση του σώματος. Η τεχνική περιλαμβάνει το να καθόμαστε σε μία στάση που να είναι άνετη για εμάς, μία θέση κατά την οποία να μπορούμε να καθόμαστε για πολλή ώρα, χωρίς να κινούμαστε και χωρίς αυτή να συμβάλλει στην τάση να αποκοιμηθούμε. Κάθε κίνηση την ώρα του διαλογισμού διασπάει την προσοχή. Ακόμα, κανένα μέλος του σώματος δεν πρέπει να ακουμπάει κάποιον άλλον, καθώς αν αυτός κινηθεί, θα ενοχλήσει τον διπλανό του.

Οδηγίες για τον Διαλογισμό SOS:

Κλείστε τα μάτια

Κλείστε τα μάτια σας πολύ απαλά, με έναν χαλαρό τρόπο, όπως όταν πηγαίνετε για ύπνο.

Η προσοχή σας πρέπει να είναι σε απόλυτη εγρήγορση

Η προσοχή σας πρέπει να είναι σε απόλυτη εγρήγορση. Προσπαθήστε να μη βάζετε ένταση στα μάτια σας και να μην κοιτάζετε προς τα πάνω.

Eστιάστε το βλέμμα σας

Eστιάστε το βλέμμα σας περίπου 20 με 25 εκ. στο σκοτάδι που βρίσκεται ακριβώς μπροστά σας.

Νοερά επαναλαμβάνετε μία λέξη που να σας δίνει ηρεμία

Νοερά επαναλαμβάνετε μία λέξη που να σας δίνει ηρεμία

Καθίστε με αγάπη

Καθίστε με αγάπη και ήρεμα, για να δείτε τι θα εμφανιστεί, σαν να παρακολουθείτε μία ταινία.

Μάθετε Διαλογισμό από έναν Πνευματικό Διδάσκαλο

Αν κάποτε προσπαθήσετε να μάθετε κάτι καινούριο θα πρέπει να βοηθηθείτε από κάποιον, ο οποίος να έχει ήδη υψηλή κατάρτιση στο αντικείμενο αυτό. Είτε είναι μία καινούρια γλώσσα είτε μία νέα μορφή τέχνης ή ένα πείραμα οργανικής χημείας, η υψηλή κατάρτιση απαιτεί τη μετάδοση γνώσης από έναν ειδικό.

Ο διαλογισμός είναι μία επιστήμη και γι’ αυτό δεν είναι διαφορετική η ανάγκη για έναν δάσκαλο. Παρόλο που η θεωρία του διαλογισμού μπορεί να διδαχθεί μέσα από ένα βιβλίο, ο διαλογισμός είναι βασικά μία εμπειρία πρακτικής άσκησης. Η πρόοδος και η επιτυχία σε αυτήν την πρακτική υποδεικνύουν την ανάγκη για έναν δάσκαλο, έναν ειδικό που να έχει ήδη επιτύχει τον στόχο του διαλογισμού. Αυτός ο ειδικός μπορεί να μας καθοδηγήσει στο πώς να συγκεντρώνουμε την προσοχή μας στην Έδρα της Ψυχής μας.

Όπως ένας δάσκαλος χημείας μπορεί να μας βοηθήσει να κατανοήσουμε και να ερμηνεύσουμε τις παρατηρήσεις που κάνουμε σ’ ένα εργαστήριο, έτσι και ένας πνευματικός ειδήμονας μπορεί να μας βοηθήσει να κατανοήσουμε και να οδηγηθούμε στα διάφορα στάδια της πνευματικής μας ανάπτυξης. Κάποιος που έχει κατακτήσει το αντικείμενο της πνευματικότητας δε θεωρείται μόνο δάσκαλος ή οδηγός, αλλά είναι επίσης και πνευματικός Διδάσκαλος.

Όντας και ο ίδιος κάποτε μαθητής, ο πνευματικός Διδάσκαλος είναι ιδιαίτερα ενήμερος για τις πολυπλοκότητες και τις προκλήσεις που βρίσκονται μπροστά μας. Με συναίσθηση και φιλευσπλαχνία, ο πνευματικός Διδάσκαλος μας οδηγεί βήμα βήμα στο πνευματικό μας ταξίδι, ενώ παράλληλα μας βοηθά να ξεπερνούμε τις προκλήσεις της καθημερινής ζωής.

7 Βήματα για την Εδραίωση της Καθημερινής Πρακτικής του SOS Διαλογισμού

Είστε νέοι στην τεχνική του διαλογισμού της Επιστήμης της Πνευματικότητας ή ενδιαφέρεστε να ενδυναμώσετε την πρακτική του διαλογισμού που ήδη ασκείτε; Εδώ είναι μερικά βήματα προς την εδραίωση της καθημερινής άσκησης διαλογισμού:

Δημιουργήστε έναν χώρο

Βρείτε ένα μέρος στο σπίτι σας που μπορείτε να αφιερώνεστε στην πρακτική διαλογισμού σας. Δε χρειάζεται να έχει κάτι ιδιαίτερο. Απλά να είναι ένα ήσυχο σημείο μακριά από ενοχλήσεις, στο οποίο να μπορείτε να ηρεμείτε και να αποσύρεστε από τον κόσμο. Επιλέξτε μία καρέκλα, μαξιλάρι ή ό,τι άλλο ίσως χρειαστεί, για να ηρεμεί το σώμα σας και να νιώθει άνετα. Αποφασίστε να χρησιμοποιείτε αυτόν τον συγκεκριμένο χώρο για τις πνευματικές σας ασκήσεις. Όταν το κάνετε, ο χώρος αυτός θα αποτελεί μία υπενθύμιση της δέσμευσης που έχετε κάνει προς τον εαυτό σας.

Βρείτε τον καλύτερο χρόνο

Κάθε στιγμή της ημέρας είναι μία καλή ώρα για διαλογισμό. Είναι καλύτερο ωστόσο να βρείτε έναν χρόνο που θα είστε πλήρως σε εγρήγορση και πιθανόν να αποσπάται ελάχιστα η προσοχή σας. Νιώστε ελεύθερα και στην αρχή πειραματιστείτε. Δοκιμάστε διαφορετικές ώρες της ημέρας και δείτε τι λειτουργεί καλύτερα για εσάς. Πότε είστε περισσότερο ξύπνιοι; Πότε μπορείτε να έχετε απόλυτη συγκέντρωση; Πότε έχετε τη μικρότερη νοητική παρεμβολή; Δώστε στον εαυτό σας μία εβδομάδα ή δύο, για να καθορίσετε τη σωστή ώρα. Αφού αποφασίσετε την καλύτερη ώρα, παραμένετε σε αυτήν.

Κάνετε μικρά βήματα

Ξεκινήστε με μία μικρή συνεδρία διαλογισμού 10 λεπτών στην αρχή. Αργότερα, προσθέστε 5 λεπτά στον χρόνο σας, χωρίς βιασύνη. Αρχικά, είναι πιο σημαντικό ο νους να αποκτήσει τη συνήθεια τού να κάθεται την ίδια ώρα κάθε ημέρα, παρά να πιέσετε τον εαυτό σας να καθίσει για μακρύτερο χρονικό διάστημα.

Κρατήστε ημερολόγιο προόδου

Καταγράφετε τον χρόνο που διαθέσατε στην πρακτική σας, τις εμπειρίες σας κατά τον διαλογισμό, καθώς και οποιεσδήποτε δυσκολίες και προκλήσεις συναντήσατε ή μικρούς στόχους που έχετε ορίσει για τον εαυτό σας ή ορόσημα που επιτύχατε.

Προγραμματίστε την πρακτική διαλογισμού

Αν δεν είναι στην καθημερινή σας λίστα ο διαλογισμός, οι πιθανότητες είναι ότι δε θα φτάσετε στο σημείο να διαλογίζεστε κανονικά. Δράστε προνοητικά και προγραμματίστε κάποιον χρόνο για διαλογισμό κάθε μέρα.

Βρείτε έναν σύντροφο για τον διαλογισμό σας “meditation buddy”

Οι άνθρωποι που ασκούνται στο γυμναστήριο παρατηρούν ότι έχοντας κανείς έναν φίλο με τον οποίο ασκείται μαζί του, τον κάνει να πηγαίνει συστηματικά στο γυμναστήριο. Δοκιμάστε το ίδιο και με τον διαλογισμό! Παρόλο που ο διαλογισμός είναι μία ατομική δραστηριότητα, το να έχετε έναν φίλο που αρχίζει το πνευματικό ταξίδι με εσάς μπορεί να σας κρατήσει κινητοποιημένους και αυτό θα ενισχύσει τη δέσμευσή σας προς την πρακτική.

Να είστε συστηματικοί στην πρακτική σας

Οποιαδήποτε ώρα της ημέρας διαλέξετε, προσπαθήστε να κάθεστε σε διαλογισμό την ίδια ώρα κάθε ημέρα. Όταν το κάνετε αυτό, καλλιεργείτε μία συνήθεια, παρόμοια και με τις άλλες καθημερινές συνήθειες που έχετε αναπτύξει, όπως το βούρτσισμα των δοντιών σας, αφού ξυπνήσετε και πριν τον ύπνο σας.

Εστιάζεστε σε ένα πράγμα κάθε φορά

Με τον σημερινό πυρετώδη ρυθμό ζωής δεν είναι ασυνήθιστο να κάνουμε πολλά πράγματα συγχρόνως κατά τη διάρκεια της ημέρας. Στην προσπάθειά μας να αναλαμβάνουμε πολλές εργασίες ταυτόχρονα, αποτυγχάνουμε. Αντίθετα, θα πρέπει να εστιαζόμαστε ολοκληρωτικά σε ένα μόνο πράγμα. Οι έρευνες δείχνουν ότι η ταυτόχρονη ενασχόληση με πολλά έργα μειώνει τη δραστηριότητα των νευρώνων σε περιοχές του εγκεφάλου που σχετίζονται με την προσοχή και τη συγκέντρωση. Αυτό σημαίνει ότι, όταν κάθεστε για διαλογισμό, με την πολλαπλή ενασχόληση είναι πιο δύσκολο να συγκεντρωθείτε. Όταν μάθετε να κάνετε ένα πράγμα την κάθε φορά, αυξάνεται η ικανότητα εστίασης της προσοχής σας. Έτσι, θα μπορείτε να εμπλουτίζετε τον διαλογισμό σας με περισσότερη συγκέντρωση.

Να έχετε επίγνωση των επιδράσεων που δέχεστε κατά τη διάρκεια της ημέρας

Οι καθημερινές επαφές σας με τους άλλους αφήνουν τα αποτυπώματά τους στον διαλογισμό σας. Όταν έχετε μια καλή μέρα κατά τη διάρκεια της οποίας οι σχέσεις σας υπήρξαν ειρηνικές και ευτυχισμένες, είναι πιο εύκολο να ακινητοποιήσετε τον νου σας όταν κάθεστε για διαλογισμό. Όταν έχετε μία δύσκολη ημέρα και νιώθετε θυμό προς τους συνεργάτες σας ή τα μέλη της οικογένειάς σας, ίσως θα είναι δύσκολο να εστιάζεστε κατά τη διάρκεια του διαλογισμού. Όταν είστε ειρηνικός και στοργικός στις σχέσεις σας με όλους, θα υπάρχει λιγότερη ταραχή στη ζωή και αυτό θα σας βοηθήσει, καθώς θα κάθεστε σε διαλογισμό.

Αναπτύξτε πάθος και ζήλο

Ρωτήστε οποιονδήποτε νικητή χρυσού μεταλλίου για το μυστικό της επιτυχίας του και θα σας πει ότι αγαπά αυτό που κάνει. Οι ειδικοί οποιουδήποτε τομέα επιδεικνύουν ένα εξαιρετικό επίπεδο πάθους για την τέχνη τους. Δεν υπάρχει διαφορά και στον διαλογισμό. Καθίστε για διαλογισμό με την πιο ειλικρινή επιθυμία να αναπτυχθείτε πνευματικά και να βιώσετε την αγάπη του Θεού. Αυτή η ειλικρινής πρόθεση θα σας βοηθήσει πολύ.

Επιμένετε

Ο διαλογισμός είναι το ταξίδι, δεν είναι ο προορισμός. Θα υπάρχουν σκαμπανεβάσματα κατά τη διάρκεια της διαδρομής. Μερικές μέρες η ακινητοποίηση του νου θα συμβαίνει εύκολα, ενώ άλλες μέρες θα αγωνίζεστε να ακινητοποιείτε ακόμα και το σώμα. Να είστε ευγενικοί με τον εαυτό σας και να συνεχίζετε να προχωράτε σταθερά προς τους στόχους του διαλογισμού.
